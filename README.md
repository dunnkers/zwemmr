# zwemmr

Find swimming pool opening hours and available time slots in Dutch cities.

## Quickstart

```bash
# Install uv (if not already installed)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Install dependencies
uv sync

# Run tests
uv run pytest

# Lint and format
uv run ruff check
uv run ruff format --check

# Type check
uv run ty check
```
